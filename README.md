## Bracelet Hunt: AI poker coach

[`poker-coach/`](poker-coach/) is a browser-based no-limit hold'em trainer. You play WSOP-style tournaments against AI opponents modeled on famous pros, get GTO-approximate feedback on every decision, and the app learns your style and leaks over time.

```bash
cd poker-coach && npm start   # http://localhost:5173
```

See [poker-coach/README.md](poker-coach/README.md) for details.
